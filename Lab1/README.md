# Lab 1: Java Maven and MySQL JDBC Connection

## Description

This assignment demonstrates how to connect a Java
application to a MySQL database using JDBC.

## Technologies Used

- Java
- Apache Maven
- MySQL
- JDBC
- MySQL Connector/J

## Operations

- Establish a database connection.
- Create database tables.
- Update database records.
- Delete database records.

## How to Run

1. Open the Lab1 project in IntelliJ IDEA.
2. Make sure MySQL Server is running.
3. Configure the database credentials securely.
4. Run the JDBCDemo class.
